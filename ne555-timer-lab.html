One-sentence Position 一句话定位 READ THIS FIRST

NE555 是一颗模拟+数字混合的集成电路：内部用两个电压比较器（模拟电路）判断电平大小，用 RS 触发器（数字逻辑）记住当前结果，再用推挽输出级（功率电路）驱动外部负载。它本身既不产生振荡、也不计时——一切定时时间与振荡频率都依靠外部的 RC（电阻+电容）充放电过程来实现，这是理解 555 的第一原则。

官方额定供电 5~15V（工作范围约 4.5~16V），输出电路可灌入或拉出最高约 200mA 电流；5V 供电时输出电平与 TTL 兼容。

易混点：7 脚不是输出脚

它只是内部 NPN 管的集电极：导通 = 对地接通，截止 = 浮空高阻。必须配合外部 RC 才有意义，不能把它当逻辑信号输出使用。

Knowledge base
Linked to architecture

或非门 RS 触发器与双稳态锁存

两个 2 输入或非门交叉耦合：一个门的输出接到另一个门的输入。R=1 强制 Q=0；S=1 强制 Q=1；R=S=0 时电路靠正反馈维持原状态，这就是双稳态记忆的硬件载体。

它没有时钟，只靠 R / S 脉冲改写，之后一直保持到下次触发。555 内部设计保证 R、S 不会同时为 1，避免非法状态。

比较器 ≠ 运算放大器

运放通常靠负反馈工作在线性区，输出与输入差分成比例；比较器通常开环，只要两输入有微小差值，输出就直接跳到饱和高 / 低电平。

555 内部用的是专用比较器：它们只负责判断“THRESH 是否超过 2/3VCC”和“TRIG 是否低于 1/3VCC”，把模拟电压翻译成数字动作。

PNP / NPN 与推挽拉 / 灌电流

NPN：基极高电平导通，集电极—射极接通；放电管就是 NPN，导通时把 7 脚拉到地。PNP：发射极接正电源，输出高时把电流推给负载。

推挽级 = 上 PNP + 下 NPN。两管互补轮流导通，使 3 脚既能拉电流（source）也能灌电流（sink），约 ±200mA。

为什么输出级取 Q 的反相 /Q 驱动推挽？

触发器 Q 端本身驱动能力很弱，带不动负载。因此内部取 Q 的反相信号 /Q，经缓冲后去控制推挽级（上 PNP、下 NPN），才能获得驱动负载所需的拉电流与灌电流。

/Q 同时驱动放电 NPN 管：Q=0、/Q=1 时放电管导通，7 脚对地；Q=1、/Q=0 时截止，7 脚高阻。

RC 充放电指数公式与 ln2 / ln3

电容电压不能突变，按指数趋近目标值：充电 V(t)=VCC−(VCC−V0)e−t/RC，放电 V(t)=V0e−t/RC。时间常数 τ=RC。

从 0 充到 2/3VCC：t = RC ln3 ≈ 1.1RC；在 1/3 与 2/3 之间走完一段：t = RC ln2 ≈ 0.693RC。三种模式的所有时间公式都由这两个对数推出。

    5脚接 0.01µF 去耦电容：抑制基准电压抖动、防自激、防误触发，不用控制电压时必接。
  • 02
    电源去耦：8脚 VCC 与 1脚 GND 就近并一只 100nF 陶瓷电容，滤除电源噪声。
  • 03
    4脚 RESET：悬空不稳定，实际电路必须接 VCC；需要暂停时再拉低。
  • 04
    元件范围：电阻一般几百 Ω ~ 1MΩ（过大漏电影响精度，过小功耗大），电容取 nF ~ µF 级。
  • 05
    未用输入脚：接合适电平，防止悬空误触发。

考前扫雷：9 个高频误区

这些点几乎覆盖了 NE555 初学者 80% 的判断错误。建议做完仿真后再逐条核对一次。

Common mistakes
Read before the exam
展开常见易错点 / 考前扫雷9 COMMON PITFALLS · CLICK TO EXPAND 9 条
  1. 555 本身不是振荡器。它是“比较器 + 触发器”的混合器件，振荡 / 定时全靠外部 RC。
  2. 7脚 DIS 是集电极开路，不是逻辑输出。不能直接当信号输出脚使用，必须配合外部上拉或 RC。
  3. 单稳态是暂态电路，双稳态不是。单稳态触发一次只出一个脉冲，然后自动回稳态；双稳态永久保持到下次触发。
  4. 无稳态电容充不到 VCC，也放不到 0V。它只在 1/3~2/3 VCC 之间摆动。
  5. 无稳态默认占空比必大于 50%。充电经 R1+R2、放电只经 R2，高电平更长；要接近 50% 需给 R2 并联二极管。
  6. 单稳态触发脉冲必须窄于输出脉宽。若 2 脚长期维持低电平，电路无法正常复位。
  7. 比较器 ≠ 运放。比较器输出饱和电平（非线性），运放可在线性区放大。
  8. 输出级用 /Q（反相）驱动推挽。因为触发器 Q 端驱动能力不足，必须借助推挽输出级才能带负载。
  9. 4脚低电平强制复位，优先级最高。不受 2 脚、6 脚控制，正常工作时必须接 VCC。
自检口诀：先问“稳态有几个”，再问“阈值从哪来”，最后问“电流走哪条路”。

压控振荡器 VCO

NE555 的一句话定位

NE555 是一颗模拟+数字混合的集成电路：内部用两个电压比较器（模拟电路）判断电平大小，用 RS 触发器（数字逻辑）记住当前结果，再用推挽输出级（功率电路）驱动外部负载。它本身既不产生振荡、也不计时——一切定时时间与振荡频率都依靠外部的 RC（电阻+电容）充放电过程来实现，这是理解 555 的第一原则。

官方额定供电 5~15V（工作范围约 4.5~16V），输出电路可灌入或拉出最高约 200mA 电流；5V 供电时输出电平与 TTL 兼容。
