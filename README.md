# NE555 定时器原理实验室

> 把 NE555 的内部结构、阈值判断与三种工作模式，做成一张可点击、可缩放、可仿真的交互式知识地图。

面向电子初学者的单文件学习页。无框架、无 CDN、无外部依赖，双击 HTML 即可运行。

## 内容

- **内部结构探索台**：全宽可缩放框图，点击模块或引脚打开知识卡片；支持电流 / 信号流可视化、信号流演示与全屏查看。
- **三种模式仿真**：单稳态、无稳态、施密特 / 双稳态；实时修改 R、C、VCC 与 5 脚控制电压，同步更新波形和计算结果。
- **配套知识**：8 脚定义、比较器 vs 运放、三极管、RC 指数公式、模式速查、易错点与拓展应用。

## 使用

打开 `index.html`，或把 `ne555-timer-lab.html` 直接拖进浏览器。

无需服务器、npm 或任何外部网络资源。

## 技术

HTML + CSS + 原生 JavaScript · Canvas + SVG · 响应式布局。

> 教学示意，非精确电气原理图；实际设计请以 NE555 数据手册为准。
